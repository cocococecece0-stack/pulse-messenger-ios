# ПУЛЬС — Мессенджер

Нативный iOS-мессенджер уровня продакшена: чаты, каналы, группы, звонки, истории, контакты, темы, поиск, локальная аналитика. Всё рисуется кодом — ни одного внешнего ассета.

## Что внутри

- 29 чатов, 300+ сообщений, 14 историй, 18 звонков, 24 контакта — живой демо-контент.
- Умные ответы, реакции, ответы на сообщения, закрепление, редактирование, удаление.
- Голосовые сообщения с волновой формой, файлы, геолокация, ссылки, стикеры, фото.
- Папки, поиск, архив, избранное, непрочитанные, mute, typing-индикатор.
- Звонки с анимированным оверлеем, таймером и кнопками mute/speaker/video.
- Истории с прогресс-барами, реакциями и ответами.
- Обзор сервисов, статистика, уведомления, сохранённые сообщения, медиатека.
- 3 темы оформления, хаптики, локальные уведомления, экспорт данных.
- About-экран на HTML/CSS внутри WKWebView.

## Сборка

GitHub Actions собирает unsigned IPA на `macos-26-intel`, проверяет отсутствие подписи, выкладывает артефакт `Pulse-Messenger-unsigned-IPA` и публикует GitHub Release `v<run>`.

Bundle ID: `com.efremov.pulsemessenger`.

Автономный скрипт: `pulse-messenger.sh` — создаёт проект, коммитит, пушит и запускает CI.
